## 三、一键复现

```bash
cd <项目根目录>
export PYTHONPATH=$PWD/src
python -m q3_explain.run_all --epochs 60        # 完整流程，V100 上约 1 分钟
python -m q3_explain.run_all --quick            # 6 epoch 冒烟测试（验证链路可用）
python -m q3_explain.invariance_check           # 掩码/不变式验收（A–F 六项）
python -m q3_explain.audit_extra                # 测试划分指标、残差、Shapley 汇总、位置→秒表
python -m q3_explain.seed_stability             # 5 个随机种子的稳定性（GPU 上约 3 分钟）
python -m q3_explain.permutation_test           # 置换检验：注意力随机重排的经验零分布
```

可选参数：`--epochs`（默认 60）、`--hidden`（默认 96）、`--seed`（默认 20260924）。

流程七步：**载入数据 → 逐维标准化（仅 train 拟合）→ 训练（按验证集 macro-F1 选模）→
验证集评价与错误归因 → 三组解释忠实度检验 → 生成附件4 预测与解释 → 报告与图表**。

**幂等性**：若 `work/q3/att4_time_map.json` 已存在则复用（如需强制重建，先删除该文件）。

## 五、数据集处理规则（**六条必读**）

| # | 规则 | 依据与后果 |
|---|---|---|
| 1 | **文本缺失必须用 `text_bert` 第 1 通道掩码检测，不能用 `x == 0`** | `text` 的填充值是**非零**的（全表零元素比例 0.0%）。直接对 50 步取平均 vs 掩码池化，相对 L2 差 **mean 0.4343 / max 1.1189** |
| 2 | **audio/vision 必须逐维标准化，统计量只在 train 的有效步上拟合** | `audio` 第 0 维范围 [0,500]、其余 73 维 ±50 → 标准差异比 **394×**；整表统一 z-score 后 dim0 仍主导 |
| 3 | **无效位置（掩码外）一律置零** | 保持"填充 = 0"的约定，避免编码器把填充当信号 |
| 4 | **不可用模态在门控 logits 上硬置 -inf** | 否则会给"没有数据"的模态赋权，输出荒谬的主要参考模态 |
| 5 | **附件2 `test` 划分不参与任何选择** | 段031 要求"在验证集上选择"。实测附件4 有 5/20 与附件2 `test` 逐值一致、落在 `valid` 的 0 条 |
| 6 | **证据时间必须用词级强制对齐，禁止 `j·D/50` 均匀切分** | 这 50 个位置是词片段轴（`掩码长度 = 音频有效位置数 + 2`，20/20 偏移恒为 2）。两种做法的差异均值 1.587 s / 最大 3.595 s，最差样本 2.29× |

**标签定义**（与问题二一致）：Negative `[-3, -0.3333]`、Neutral `{0}`、Positive `[+0.1667, 3]`；
`0` 仅属中性；`+0.1667` 是合法正向，**不可当作近中性并入中性类**。

## 六、参数配置

全部参数见 **`config_q3.yaml`**（冻结配置）。摘要：

| 类别 | 关键参数 |
|---|---|
| 模型 | hidden 96；每模态 1 层 TransformerEncoder，4 头，`dim_feedforward = hidden*2`，`norm_first=True`；时间注意力 `Linear(96,48)→Tanh→Linear(48,1)`；门控 `Linear(288,96)→GELU→Linear(96,3)` |
| 目标函数 | `L = CE_w(极性) + 1.0 × MSE(强度)`，`CE_w` 用逆频率类权重 |
| 训练 | AdamW，lr 1.5e-3，wd 1e-4，CosineAnnealingLR，batch 128，最多 60 轮，早停 patience 12，modality_dropout 0.1，seed 20260924 |
| 选模 | 按**验证集 macro-F1** 选最佳 epoch（实测第 4 轮，第 16 轮早停） |
| 决策阈值 | 固定 `argmax`（对称判决，等价阈值为 0）；**没有可调阈值** |
| 数据 | `aligned_50`，50 个位置，`content_slots = 48` |

## 九、边界与已知限制（论文须如实说明）

1. **证据时间口径**：秒级定位来自"附件4 自带 mp4 + 词级强制对齐"，**不是官方提供的逐词时间戳**（附件4 未提供）。子词→词的映射为**精确映射**：用 bert-base-uncased 词表（随包发布 `vocab/bert-base-uncased_vocab.txt`）重建 token 序列，并与数据自带 `text_bert[0]` 逐位比对（附件4 20/20、附件2 抽样 400/400 一致）。
2. **附件4 不是完全独立的测试集**：20 条中 **5 条与附件2 `test` 划分逐值一致**（同源留出）；**落在 `valid` 的为 0 条**，故选模无泄漏。论文宜称"同源留出样本"。
3. **样本 13 视觉整条为零**：与题面段017「附件4 三模态信息完整」**矛盾**。门控 −inf 硬掩码实测把该模态权重置 0（`vision: 0.000`）。
4. **中性类召回 0.3913** 是主要瓶颈（83/184 中性被判为正向）；已报 macro-F1 而非仅 accuracy。
5. **3 条样本（05、15、18）的门控判断未被留一扰动复核确认**，已在解释卡中标注 ⚠️，未掩盖。
6. **视听两路的相对次序不稳定**：留一扰动下文本在 5 个随机种子上都居首，视觉与语音的次序有 1 次反转；置换检验中语音虽然显著（p=0.0012）但绝对效应量只及文本约 1/43，视觉不能拒绝零假设（p=0.1362）。本文只主张文本明显高于另两路，不对这两位的次序作结论。
7. **附件2 中超过 48 个子词的长句会被截断**（输入契约固定为 50 个位置），这类样本的解释结果需谨慎对待。

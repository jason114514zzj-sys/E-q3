## 一、这个包解决什么问题

模型给出的"关键证据"只能是**位置序号**（"第 17 个位置"）。
题面段029 要求证据"**可对应至原始文本片段、语音时段或视觉关键帧**"，
段017 说明附件4 配套的 20 条原始视频就是用来"**把模型给出的关键证据时间位置回看至**"的。

所以必须把"位置"变成"秒"。**这个换算不能靠在脑子里平均分。**

## 二、⚠️ 先说被推翻的那个做法

上一版文档里写过：

```
位置 j ↔ 原始时间 [ j·D/50 , (j+1)·D/50 ]        ← ❌ 错的，已废除
```

这个式子**从未经过检验**，它默认"50 个位置是 50 个等长时间片"。**实测不是。**

### 证据 1：这 50 个位置是**词片段（word-piece）轴**

逐条读附件4 对齐版（`np.sum(text_bert[1] > 0)` vs 音频非全零行数）：

```
20/20 条满足：  text_bert 注意力掩码长度  =  音频有效位置数 + 2
               偏移恒为 2（首尾各一个特殊 token），corr = 1.000
音频有效位置数范围：11 ~ 48      ← 不是恒为 50
```

- 偏移恒为 2，对应 `[CLS]` 与 `[SEP]`
- 上限 48，与问题一早已冻结的 `config.yaml`：`content_slots: 48  # 位置 0 给 [CLS]，末位给 [SEP]` **完全吻合**
- 若真是等长时间片，每条样本都会用满 50 个位置、有效数恒为 50 —— 实测不是

### 证据 2：硬按平均分，偏差有多大

| 指标 | 数值 |
|---|---|
| 与词级强制对齐的偏差（均值） | **1.968 s** |
| 与词级强制对齐的偏差（最大） | **3.627 s** |
| 最差样本 | **15 号**：平均法给 2.053 s，真实 5.680 s → **差 2.77 倍** |

**2.77 倍是什么概念**：评阅人点开视频，拖到 2.05 秒看到的画面和"证据"毫无关系。
而"证据可回看"恰恰是问题三被单独设问的原因。

## 三、✅ 本包的做法：真实词级强制对齐

```
附件4 的 20 条 mp4
  ↓ ffprobe  取真实时长 D（这些视频头部的 nb_frames 元数据不可信，100 条里 90 条虚报）
  ↓ ffmpeg   解成 16 kHz 单声道 f32le
  ↓          算 10 ms 一跳的 RMS 能量包络
  ↓          用 raw_text 逐词做【约束式单调强制对齐】
  ↓            硬约束：首词起于 0.0、末词止于 D、严格单调、语速 ∈ [1, 6] 词/秒、
  ↓                    边界向能量谷吸附（停顿感知）
  ↓ 每个词得到真实的 [start, end] 秒
```

实测质量：**20/20 条覆盖率 1.000**，语速 1.80–4.01 词/秒，全部从 0.000 s 起。
代码：`src/q3_explain/evidence_time.py`（复用问题一的 `q1_alignment.monotonic_align`）。

### 位置 → 词 → 秒

```
位置 j（1 基，j = 1..n_positions；位置 0 是 [CLS] 占位，全零）
   ↓  按 token 序号比例落到词：  word_index = round( (j-1)/n_positions × n_words )
词 word_index
   ↓  查对齐表
[start_sec, end_sec]
```

`position_time_map.csv` 已经把这条链算好，**直接用即可，不必自己复算**。

### `position_time_map.csv` 列

| 列 | 含义 |
|---|---|
| `sample_id` | `01`..`20`（附件4 自己的 `id` 字段，不是 MOSEI 的 video_id） |
| `position` | 特征轴上的位置序号，**1 基**，范围 `1..n_positions` |

| `duration_sec` | 该样本 mp4 的真实时长 |

## 五、三条必须知道的口径限制（论文里要写）

1. **子词 → 词是比例近似。** 本机没有 BERT 分词器（服务器无法访问 HuggingFace），
   无法把第 j 个 word-piece 精确还原到第几个词。实测 `n_positions / n_words` 均值约 1.2，
   所以**通常误差在 1 个词以内**；但**每个词自身的起止时间是真实对齐结果**，秒级定位不依赖均匀假设。
2. **视觉与音频共用同一条位置轴。** 实测对齐版 19/20 条满足"音频有效位置数 == 视觉有效位置数"
   （唯一例外见第 3 条），因此本映射**同时适用于视觉关键帧定位**。
3. **样本 13 的视觉特征整条为零。** 题面段017 说附件4"三模态信息完整"，但实测 13 号的
   对齐版 vision 50 个位置**全部为零**，未对齐版也只有 17/500 非零（同批其他样本约为音频的 75%）。
   → 用到视觉证据时**必须把 13 号的视觉排除**，否则会得到荒谬解释。
   （问题三的门控已用 −inf 硬掩码把该模态权重置 0。guard **D5** 已把这条变成机检项。）

## 六、自查片段

```python
import pandas as pd

m = pd.read_csv("position_time_map.csv")
# 1) 覆盖 20 条、位置数正确
assert m.sample_id.nunique() == 20
# 2) 时间单调不减，且落在 [0, duration] 内
for sid, g in m.groupby("sample_id"):
    g = g.sort_values("position")
    assert g.start_sec.is_monotonic_increasing, sid
    assert (g.start_sec >= 0).all() and (g.end_sec <= g.duration_sec.max() + 1e-6).all(), sid
    assert (g.end_sec >= g.start_sec).all(), sid
# 3) 单调不减：位置越大时间越晚（对齐是单调的）
print(m.groupby("sample_id").duration_sec.first().describe())
```

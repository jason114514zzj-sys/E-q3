## 五、本轮校验的新发现（含对我自己的更正）

### 5.1 🟥 重要更正：`j·D/50` 均匀时间片假设是错的

**上一版的问题三解题报告与队友清单核查文档里都写着：**
> 「位置 j ↔ 原始时间 `[j·D/50, (j+1)·D/50]`（已验证）」

**本轮复算把它否掉了。**

(a) **这 50 个位置不是等长时间片，而是词片段（word-piece）轴。** 直接读附件4 对齐版：

```
20/20 条满足：text_bert 注意力掩码长度 = 音频有效位置数 + 2（偏移恒为 2，corr = 1.000）
音频有效位置数范围 = 11 ~ 48（不是恒为 50）
```

偏移恒为 2 正好对应首尾的特殊 token；上限 48 与 `config.yaml` 里问题一早已冻结的
`content_slots: 48  # 位置 0 给 [CLS]，末位给 [SEP]` **完全一致**。
若这 50 个位置是等长时间片，则每条样本都会用满 50 个位置、有效数恒为 50——实测不是。

(b) **均匀假设的误差量级**（附件4 的 20 条）：

| 项目 | 数值 |
|---|---|
| 词级对齐与按位置均分的差异（均值） | **1.587 s** |
| 词级对齐与按位置均分的差异（最大） | **3.595 s** |
| 最差样本 | **15 号**：均匀给 2.053 s，真实 5.680 s（**2.77 倍**） |

**后果**：解释卡里"关键证据在第 X 秒"会被指到**完全错误的位置**，而题面 R6/X6 恰恰要求证据"可回看至原始片段"——这是**评阅人真的会去点播放器核对**的一项。

(c) **已做的修复**：
1. 新增 `src/q3_explain/evidence_time.py`：对附件4 的 20 条 mp4 做 **ffmpeg 解码（16 kHz 单声道，10 ms 跳距）→ 能量包络 → 问题一同一套约束式单调强制对齐**，得到每个词的起止秒；20/20 覆盖率 1.000，语速 1.80–4.01 词/秒，全部从 0.000 s 起。

4. 新增 guard **G6「证据时间有据可依（词级对齐，非均匀切分）」**：逐行检查 CSV 的时间是否**锚定在某个真实词边界上**（容差 0.02 s）、是否越界、覆盖率是否 ≥0.9，并**独立重算**上面那条"偏移恒定"不变量。实测：锚定 **20/20**，越界/离格 0，覆盖率 <0.9 的 0 条，偏移 2~2。

## 七、问题三解题思路（通俗版）

### 7.1 一句话

**让模型像"三个专家各自看一遍视频、各自指出自己最在意的片段，最后投票决定整体情绪"——投票的票数、各自指的片段，就是题目要的解释。**

### 7.2 三个专家各自干什么

把同一条视频切成三路：

| 专家 | 他"看"到的 | 他做什么 |
|---|---|---|
| 文本专家 | 这句英文的 768 维语义向量序列（50 个词位） | 用一层 Transformer 看完整句话，理解"上下文里这句话到底什么味道" |
| 语音专家 | 74 维声学特征序列 | 同上，看语调、停顿、重音的变化 |
| 视觉专家 | 35 维表情/姿态特征序列 | 同上，看面部与动作的变化 |

**为什么三个人要各看各的、不一开始就混在一起？**
如果一开始就把三路拼起来，最后就没法说清"到底是文本起作用还是表情起作用"。
分开编码，才有资格谈"作用程度"。

### 7.3 每个人还要指出"我最在意哪几段"（时间注意力）

每个专家看完后，给 50 个位置每个打一个"在意程度"，归一化成一条概率分布（这就是**注意力**）：

- 分布里最高的那几个位置 = 这个人认为"判断的依据在这里"
- **没有数据的位置要先屏蔽掉**（把分数设成 −∞ 再归一化），否则模型会对着填充的零向量"看出情绪"——这是本轮实际抓到的 bug，附件2 验证集上有 15 条样本被这么坑过

### 7.4 三个人的票数怎么来（模态门控）

把三个专家各自"看完后的总结"（一个向量）拼起来，过一个小的两层网络，输出三个非负数并且和为 1：

```
text 0.625  audio 0.143  vision 0.232     ← 这就是「模态作用程度」
最高的一项 = 主要参考模态
```

**关键约束**：如果某个模态整条没有数据，就把它那一票**硬性压成 0**，票数重新分给其他两个。附件4 的 13 号就是这样处理的。

### 7.5 最后出两个结论

- **极性头**：三分类（负/中/正）
- **强度头**：一个连续回归值

### 7.6 为什么说这套解释是"可复核"的（题目 R1 的硬要求）

注意力好看不等于有用。所以额外做两项**行为学检验**：

| 检验 | 怎么做 | 结果 |
|---|---|---|
| **忠实度（三组遮蔽）** | 分别挖掉注意力最高的 3 位（峰值组）、最低的 3 位（低谷组，与峰值组不相交）、随机 3 位（随机组，重复 5 次），看强度预测变化 | 严格三段序（峰值>随机>低谷）占比：**text 73.9%**、audio 27.5%、vision 24.0%。文本峰值/低谷 = 0.2888/0.0196 = **14.75 倍**；audio 1.34 倍、vision 1.20 倍且低谷组高于随机组 → **只有文本通过三段序检验**；置换检验（注意力随机重排的经验零分布）给出 text p=0.0002、audio p=0.0012、vision p=0.1362，语音虽显著但绝对效应量只及文本约 1/43，故语音与视觉只作参考展示、不据以解释单条样本（详见论文 7.3.3）|
| **留一模态扰动（LOMO）** | 把某个模态整条删掉，看预测变化 | 这是门控"自述"的**行为学对照**。附件4 上一致率 **17/20 = 85%**，**3 条不一致的样本（05、15、18）在解释卡里加了 ⚠️ 标注、不掩盖**；5 个随机种子下文本均居首，视听两路次序有 1 次反转，故不对这两位排序 |

### 7.7 "第几秒"是怎么算出来的（本轮修好的部分）

模型只告诉我"第 17 个位置"，而**第 17 个位置是什么时候**必须自己求：

1. 附件4 配套给了 20 条原始 mp4；
2. 用 `ffprobe` 取真实时长（这些视频头部的帧数字段**不可信**，100 条里 90 条虚报）；
3. 用 `ffmpeg` 把音轨解成 16 kHz 单声道，算 10 ms 一跳的能量包络；
4. 拿 `raw_text`（逐词文本）和能量包络做**约束式单调强制对齐**（覆盖率必须 ≥90%、语速必须在 1–6 词/秒、严格单调、首尾必须对齐到 0 和总时长）；
5. 于是每个词有了真实的起止秒 → 位置映射到词 → 词映射到秒。

**为什么不能"总时长 ÷ 50"平均分？** 因为这 50 个位置是**词位**不是等长时间片（20/20 条满足"文本掩码长度 = 音频有效位置数 + 2"，上限 48 与问题一早已冻结的 `content_slots: 48` 吻合）。硬平均的偏差均值 1.97 秒、最大 3.63 秒，最差的 15 号把 5.68 秒的证据指到 2.05 秒——**差 2.77 倍，点开视频一眼就能看出错**。

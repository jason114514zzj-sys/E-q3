本项目独立完成第三问的**可解释性建模、训练、验证与附件4 专项推理与解释**。
不依赖第一问的自生成特征，也不依赖第二问的模型或输出。

训练与选模**仅使用附件2 的 train/valid**；附件2 的 test 划分保留不用；
附件4 只在模型结构与决策规则**冻结之后**做推理。

对应题面：**段028–030（任务）**、**段031（协议与指标）**、**段049–053（论文正文）**、**段055–057（附件提交）**。

## 一、输入和标签

- 统一使用 **aligned_50** 版本：`text (N,50,768) float32`、`audio (N,50,74)`、`vision (N,50,35)`、`text_bert (N,3,50)`。
  （题面段018 要求训练、验证与专项测试保持**同一特征版本与同一输入接口**。）
- 分类标签 0/1/2 分别为 Negative / Neutral / Positive；强度在 [-3, 3]，**零仅属中性**。
  附件2 上负向范围 [-3, -0.3333]、正向范围 [+0.1667, 3]，**`+0.1667` 是合法正向**，不可当近中性并入中性类。
- 文本主表征使用附件2 官方预计算的 `text`（50×768）。
  > 说明：附件3 未提供 `text` 列，因此第二问改走 `text_bert` + 冻结编码器。三问在**各自**的
  > 「训练↔推理」之间保持同一接口，符合段018；两问的文本表征不同属接口边界。
- 附件4 的特征字段与张量维度与附件2 一致，另有 `id`（本地序号 `01`..`20`）与 `raw_text`。
- **附件4 配套的 20 个 mp4** 用于把关键证据的时间位置回看至原文/语音/视觉片段（段017）。

## 四、冻结后的附件4 推理与解释

模型结构与参数在 `models/` 中冻结（`q3_model.pt` 含 `state_dict` / `dims` / `hidden`；
`q3_training.json` 记录超参与逐轮 history），推理**不重新训练**。

输出文件 `results/附件4_预测与解释结果.csv`（**20 行 × 8 列**）：

| 字段 | 含义 | 对应题面 |
|---|---|---|
| `sample_id` | `01`..`20`（附件4 的 `id`） | — |
| `polarity` | Negative / Neutral / Positive | 段029「情感极性」 |
| `intensity` | 连续强度，落在 [-3, 3] | 段029「情感强度」 |
| `dominant_modality` | 门控 argmax | 段029「主要参考模态」 |
| `modality_weights` | `text:w,audio:w,vision:w`，三项非负且和为 1 | 段028/029「模态作用程度」 |
| `evidence_start` / `evidence_end` | 关键证据的**真实起止秒** | 段029「关键证据定位」 |
| `evidence_modality` | 证据落在 text / audio / vision | 段029 |

附带的 `results/att4_time_map.json` 给出 20 条样本的**逐词真实起止秒**，
`results/position_time_map.csv` 把它整理成「特征位置 → 词 → 秒」的平面表（564 行），
供把模型给出的位置序号回看到视频/音频片段。

> ⚠️ **禁止用 `j · D / 50` 均匀切分**。实测这 50 个位置是**词片段轴**而不是等长时间片：
> 20/20 条满足「`text_bert` 掩码长度 = 音频有效位置数 + 2」（偏移恒为 2，corr = 1.000），
> 音频有效位置数在 11~48 间变化而非恒为 50，上限 48 与内容槽位数吻合。
> 两种做法的差异：**均值 1.587 s、最大 3.595 s**，最差样本 15 号达 **2.29 倍**。

**解释的可复核性检验**

| 模态 | 遮蔽注意力**峰值**3 位 | 遮蔽**随机**3 个有效位 | 遮蔽注意力**低谷**3 位 | 峰值−低谷 | 峰值/低谷 | 严格三段序 |
|---|---:|---:|---:|---:|---:|---:|
| text | 0.3377 | 0.0767 | 0.0189 | **+0.3188** | **17.91** | **76.5%** |
| vision | 0.0423 | 0.0137 | 0.0239 | +0.0184 | 1.77 | 34.2% |
| audio | 0.0147 | 0.0101 | 0.0118 | +0.0029 | 1.24 | 35.7% |

**低谷组（注意力最低的 3 个有效位置，与峰值组不相交）是关键**：只有 text 满足
「峰值 > 随机 > 低谷」的严格三段序（76.5%），vision/audio 的低谷组还略高于随机组
（34.2% / 35.7%），说明这两路的注意力剖面对「哪个片段更关键」没有分辨力 —— 本文据此
**只对 text 主张片段级解释效力**，vision/audio 只作参考展示。三组在同一子集上比较
（text 719 条 / vision 679 条 / audio 712 条；其余样本有效位置不足 2k=6 个，如实剔除）。

门控（模型自述）与留一模态扰动（实测行为）的主导模态一致率 **15/20**，
**5 条不一致的样本在解释卡中标注 ⚠️，不掩盖**。

## 六、实现注意事项

- **文本缺失必须用 `text_bert` 第 1 通道掩码检测**。`text` 的填充值是**非零**的
  （全表零元素比例 0.0%），用 `x == 0` 判缺失会得出"文本无缺失"的错误结论；
  直接对 50 步取平均与掩码池化的相对 L2 差为 **均值 0.4343、最大 1.1189**。
- **audio/vision 必须逐维标准化，且统计量只在 train 的有效步上拟合**。
  `audio` 第 0 维范围 [0,500]、其余 73 维 ±50，标准差异比 **394×**；整表统一 z-score 后 dim0 仍主导。
- **不可用模态在门控 logits 上硬置 `-inf`**（硬约束，不是正则）。
  否则会给"没有数据"的模态赋权：在附件2 验证集上实测曾有 15 条 vision 整条缺失的样本
  被赋平均 0.2351 的 vision 权重（高于全体平均 0.1745），导致"主要参考模态 = vision"这种荒谬解释。
- **文本遮挡/无效位置一律置零**，保持"填充 = 0"的约定，避免编码器把填充当信号。
- **模块化程度 `--modality_dropout` 与门控硬掩码是两件事**：前者是正则化，后者是结构约束。
- 时间注意力在 softmax **之前**把无效位置的 logits 置 `-inf`；若先 softmax 再置零会破坏归一化。
- 图表中文依赖 `Noto Sans CJK JP`；缺失时不会报错，只会画出方框，需人工目视确认。

## 七、边界与已知限制（论文须如实说明）

1. **证据时间口径**：秒级定位来自"附件4 自带 mp4 + 词级强制对齐"，**不是官方提供的逐词时间戳**
   （附件4 未提供）。子词→词为**精确映射**：用 bert-base-uncased 词表重建 token 序列并与数据自带 `text_bert[0]` 逐位比对（附件4 20/20、附件2 抽样 400/400）；
   但每个词自身的起止时间是真实强制对齐结果。
2. **附件4 不是完全独立的测试集**：20 条中 **5 条与附件2 `test` 划分逐值一致**（同源留出样本）；
   落在 `valid` 的为 **0 条**，故选模无泄漏。论文宜称其为"同源留出样本"。
3. **样本 13 的视觉特征整条为零**，与题面段017「附件4 三模态信息完整」**矛盾**。
   门控硬掩码实测把该模态权重置 0（`vision: 0.000`）。
4. **中性类召回 0.4946** 是主要瓶颈（61/184 中性被判为正向）；已报告 macro-F1 而非仅 accuracy。
5. **验证集参与早停与最佳 epoch 选择**，因此上表属**开发评价**，不是独立测试成绩。
6. **本方案为单一种子**（`seed = 20260924`）冻结，未做多种子重复；
   与第二问的 3 种子均值/标准差报告方式不同，是当前证据范围的限制。
7. 附件4 无标签，**不能**报告 Accuracy / F1 / MAE / Pearson 等需要真值的指标。
